Como autenticación debe usar las variables de entorno GCAIS_API_KEY y GCAIS_API_BASE_URL, siempre validarlas al arrancar la aplicación

El backend debe permitir gestionar los de chats, consultarlos por reference:
Para crear un mensaje debe ser sobre /api/chats, POST
En cada mensaje debe enviar como contexto el id del contrato de manera OBLIGATORIA
Enviando un body como:
 {
  @IsString()
  @IsNotEmpty()
  chat_name: string;

  @IsString()
  @IsNotEmpty()
  service_id?: string;

  @IsString()
  @IsOptional()
  service_name?: string;

  @IsString()
  @IsNotEmpty()
  message: string;

  @IsEnum(Role)
  @IsNotEmpty()
  role: Role;

  @IsString()
  @IsNotEmpty()
  sender_name: string;

  @IsString()
  @IsNotEmpty()
  reference: string;

  @IsString()
  @IsOptional()
  client?: string;

  @IsObject()
  @IsOptional()
  media?: {
    mimetype: string;
    data: string;
  };
}


La referencia debe estar construida con la ip del cliente asi: gcais-<ip>-<id_contrato>

La estructura de un chat que retornan las rutas de consulta son:
{
  @PrimaryGeneratedColumn('uuid')
  id: string;

  @Column({ type: 'varchar', length: 255 })
  chat_name: string;

  @Column({ type: 'uuid' })
  service_id: string;

  @ManyToOne(() => Service, (service) => service.id)
  @JoinColumn({ name: 'service_id' })
  service: Service;

  @Column({ type: 'text' })
  message: string;

  @Column({ type: 'varchar', length: 255 })
  role: Role;

  @Column({ type: 'varchar', length: 255 })
  sender_name: string;

  @Column({ type: 'text' })
  reference: string;

  @Column({ type: 'varchar', length: 255 })
  client: string;

  @CreateDateColumn({ type: 'timestamp' })
  createdAt: Date;

  @UpdateDateColumn({ type: 'timestamp' })
  updatedAt: Date;
}
